SQL rules. They have no exceptions: a query that breaks any of them is refused and never runs.
- Write one read-only SELECT statement (WITH, UNION, INTERSECT and EXCEPT are allowed), at most {{max_sql_bytes}} bytes. No other statement: no INSERT, UPDATE, DELETE, CREATE, DROP, COPY, ATTACH, PRAGMA, SET or CALL, and no SELECT INTO, TABLE, VALUES, FOR UPDATE or FOR SHARE.
- Read rows only from {{sources}}, or from a WITH table you define with a name of its own. These are already tables: never read a file, never put a function in FROM (such as read_csv_auto, glob or range), never write a schema before a table name, never read system tables, and never use UNNEST, PIVOT or WITH RECURSIVE.
- Use only the listed columns and the names the query itself defines with AS, written as "column" or table."column", never with three parts.
- Call only these functions, written as f(x) and never as x.f(): {{functions}}. CAST and CASE are allowed.
- lpad and rpad: the length is a number written out, at most {{max_pad_length}}. strftime(value, 'format'): the format is written out, at most {{max_time_format_bytes}} bytes. replace: the searched text and the replacement are written out, and the replacement is not longer than the searched text. regexp_replace: the pattern and the replacement are written out; the replacement is empty, or one ASCII character when the pattern cannot match an empty string.
- At most {{max_query_depth}} query levels counting the outer query, every subquery and every WITH table; at most {{max_concat_pieces}} pieces joined with ||, concat or concat_ws in the whole query; at most {{max_literal_bytes}} bytes in one string literal; at most {{max_select_items}} columns in one SELECT; at most {{max_from_sources}} sources in one FROM, joins included; at most {{max_set_branches}} UNION, INTERSECT or EXCEPT branches in the whole query.
- Write LIMIT n only when the question asks for a number of rows, and never FETCH FIRST or LIMIT BY: the system caps the rows itself. Never filter rows for access rights: the system does that too.
