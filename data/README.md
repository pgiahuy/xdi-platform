# Dữ liệu mẫu

`samples/` chứa vài file nhỏ (dưới 1 MB) để chạy ngay và để test. Dataset thật tải bằng `./download.sh`, không commit
vào repo. `domains/` chứa gói khái niệm ngành (docs/DOMAINS.md): được commit và backend nhúng vào binary lúc biên
dịch, thêm một ngành chỉ cần thêm một file JSON.
